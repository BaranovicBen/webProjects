## Featured Projects

### Group Scheduler MVP (Latest)
A secure, privacy-first group scheduling application that finds common free time from calendar data.

**Features:**
- Enterprise-grade security (256-bit encryption, bcrypt hashing)
- Cross-platform mobile app (iOS/Android/Web via React Native + Expo)
- Fast deterministic algorithm (O(PN log N))
- Single-use sessions with automatic expiry
- iCal import with recurrence support
- Production-ready architecture

**Tech Stack:** Node.js, Express, React Native, Expo, Jest

[Full Documentation](group-scheduler/README.md) | [Quick Start](group-scheduler/QUICK_START.md)
